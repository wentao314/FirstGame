A chess engine written in **Java**.

>**🔨Work in Progress**
>

## 📖About the project
This project is a personal programming project focused on building a chess engine from scratch.

My main goal is to improve my understanding of **oject-oriented programming, algorithms, data structures, and software design** by implementing the different components of a chess engine myself.

- Chess board representation
- Piece movement and legal move generation
